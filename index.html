Connect Spotify

Linework searches Spotify for you. It runs entirely in your browser and needs a free Spotify app Client ID.

  1. Open the Spotify Developer Dashboard and create an app (choose Web API).
  2. Add this exact Redirect URI:
  3. In User Management, add the Spotify account of each person who will log in (development mode allows a few).
  4. Paste the Client ID below.

Without a Client ID, Linework still reads your drawing and opens a matching Spotify search.
